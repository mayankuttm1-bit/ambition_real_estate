# Ambition Real Estate - Luxury Web Portal

A bespoke, high-conversion real estate web portal designed for **Ambition Real Estate** operating across Ujjain, Dewas Road, and the high-growth Indore Highway corridor in Madhya Pradesh, India.

---

## 🌟 Key Features

- **Luxury Emerald & Royal Gold Aesthetic**: Custom luxury theme utilizing deep forest emerald, burnished gold/brass accents, and editorial serif typography (*Playfair Display* + *Plus Jakarta Sans*).
- **Verified Property Catalogue**: Filterable directory of prime residential duplex homes, 4-lane touch highway commercial plots, corner plots, and large-scale township land parcels with transparent per sq.ft pricing parameters.
- **Interactive Financial Tools**:
  - **EMI & 25% Booking Calculator**: Allows prospective buyers to calculate estimated monthly EMIs and plan payments based on Ambition's signature 25% token booking facility.
- **Lead Generation & Conversion**:
  - Direct 1-tap WhatsApp buttons on every property with pre-filled enquiry parameters.
  - Interactive site visit scheduling modal.
  - Stacked circular Floating Action Buttons (Call + WhatsApp) anchored on the bottom right.
- **Micro-Market Growth Guide**: Macro-analysis of Ujjain's rapid infrastructure expansion (6-lane highway, Simhastha 2028 masterplan, D-Mart commercial hub).
- **Office Location & Google Maps**: Embedded interactive map showing the registered office at 194, Mahaveer Bagh Colony, Indore - Ujjain Rd, Pawapuri Colony, Ujjain.

---

## 🛠️ Tech Stack

- **Framework**: [React](https://react.dev/) + [Vite](https://vite.dev/)
- **Routing**: [React Router](https://reactrouter.com/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Icons**: [Lucide React](https://lucide.dev/)

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher)
- npm or yarn

### Installation
```bash
# Clone the repository
git clone https://github.com/mayankuttm1-bit/ambition_real_estate.git

# Navigate to project directory
cd ambition_real_estate

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build

# Preview production build
npm run preview
```
